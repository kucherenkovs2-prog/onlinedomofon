Политика конфиденциальности

Последнее обновление: 15 сентября 2026 года

Настоящая политика описывает порядок обработки и защиты персональных данных пользователей сайта.

1. Оператор персональных данных

Оператор: укажите полное наименование организации.

Адрес: укажите юридический адрес.

Контактный email: укажите email для обращений.

2. Какие данные могут обрабатываться

При использовании сайта могут обрабатываться имя, номер телефона, адрес электронной почты, город, сведения из обращения и технические данные, необходимые для работы сайта.

3. Цели обработки данных

Данные используются для обработки заявок, обратной связи, консультаций, оформления заказов и улучшения работы сайта.

4. Передача и хранение данных

Данные не передаются третьим лицам, кроме случаев, предусмотренных законодательством или необходимых для обработки заявки с привлечением сервисов оператора.

5. Права пользователя

Пользователь может запросить уточнение, исправление или удаление своих персональных данных, направив обращение оператору по указанным контактам.

6. Контакты

По вопросам обработки персональных данных используйте контактные данные, указанные на странице «Контакты».

Перед публикацией замените выделенные поля данными организации и проверьте текст с ответственным за юридические документы.
